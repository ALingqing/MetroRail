# 命令参考

MetroRail 的全部功能都挂在主命令 **`/mr`** 下，别名 **`/metrorail`**、**`/mrail`**。

- 不带参数执行 `/mr` 会显示帮助。
- 级位支持**简写**：`/mr p1` 等价于 `/mr notch p1`。
- 所有子命令都支持 Tab 补全（受权限限制的项只在有权限时补全）。

---

## 1. 驾驶

| 命令 | 权限 | 说明 |
| :-- | :-- | :-- |
| `/mr drive [车型]` | `metrorail.drive` | 接管**最近**的矿车（你在车上则接管脚下那节），并获得驾驶权。可指定车型 id（见 `/mr vehicle list`）。 |
| `/mr release` | `metrorail.drive` | 释放驾驶权，显示本次运行里程。 |
| `/mr notch <级位>` | `metrorail.drive` | 设置牵引 / 制动级位。 |
| `/mr <级位>` | `metrorail.drive` | 简写形式。 |
| `/mr reverser <档>` | `metrorail.drive` | 换向，需停稳或低速（阈值 `drive.reverser-max-speed`）。 |

### 级位取值

| 级位 | 含义 |
| :-- | :-- |
| `p1` `p2` `p3` `p4` | 牵引 1~4 档（`p4` 满牵引） |
| `n` / `neutral` / `0` | 惰行（无牵引无制动） |
| `b1` … `b7` | 常用制动 1~7 档（`b7` 满常用制动） |
| `eb` / `emergency` | 紧急制动 |

### 换向档取值

`forward`（前进）、`neutral`（空档）、`backward`（后退）

### 驾驶权失去的情况

- 手动 `/mr release`
- 玩家**下车**
- 玩家**掉线**（`PlayerQuitEvent`）
- 插件**重载 / 关闭**（`releaseAll()`）

## 2. 车型

| 命令 | 权限 | 说明 |
| :-- | :-- | :-- |
| `/mr vehicle list` | `metrorail.use` | 列出所有已加载车型及其最高速度。 |
| `/mr vehicle info <车型>` | `metrorail.use` | 显示某车型的完整物理参数。 |
| `/mr vehicle select <车型>` | `metrorail.drive` | 把**当前会话**切换为该车型（需先在驾驶中）。 |

车型来源于 `plugins/MetroRail/vehicles/<id>.yml`，键名见 [配置参考.md](配置参考.md)。

## 3. 编组（多节矿车 = 一列车）

权限：`metrorail.train`

| 命令 | 说明 |
| :-- | :-- |
| `/mr train list` | 列出所有编组（id、节数、所属玩家）。 |
| `/mr train scan` | 把身边最近的矿车登记为一个新编组（自动编号 `c1`、`c2`…）。 |
| `/mr train create <id>` | 新建一个空编组。 |
| `/mr train append <id>` | 把身边最近的矿车加入该编组（受 `drive.max-consist-size` 限制）。 |
| `/mr train unlink <id>` | 把身边最近的矿车从该编组移出。 |
| `/mr train remove <id>` | 删除整个编组。 |
| `/mr train info <id>` | 查看编组详情。 |

「身边的矿车」判定半径见 `drive.scan-radius`（默认 8 格）。

## 4. 运行状态与里程

| 命令 | 权限 | 说明 |
| :-- | :-- | :-- |
| `/mr status` | `metrorail.use` | 显示驾驶权、速度、车型、编组、列控模式 / 状态 / MA / 完整性、Metro 对接、车型与编组统计。 |
| `/mr mileage` | `metrorail.use` | 显示自己的总里程（含当前会话）。 |
| `/mr mileage <玩家>` | `metrorail.admin` | 查询（在线或曾记录过的）某玩家的里程。 |

> 里程记录在 `mileage.yml`。清空里程的 `clearkm` 子命令**当前版本尚未实现**（规划中）。

## 5. HMI（驾驶界面）

| 命令 | 权限 | 说明 |
| :-- | :-- | :-- |
| `/mr cab` | `metrorail.drive` | 打开图形驾驶室 GUI（级位 / 换向 / 鸣笛 / 铃声 / 列控模式按钮）。 |
| `/mr hotbar` | `metrorail.drive` | 查看当前快捷栏驾驶格位设置。 |
| `/mr hotbar <1-9\|off>` | `metrorail.drive` | 设置快捷栏驾驶格位并写入 `drive.hotbar-slot`。 |
| `/mr horn` | `metrorail.drive` | 鸣笛。 |
| `/mr bell` | `metrorail.drive` | 打铃。 |
| `/mr speedunit` | `metrorail.use` | 查看当前速度单位。 |
| `/mr speedunit <kph\|mph\|block>` | `metrorail.use` | 设置速度单位（`block` 与 `block/tick` 等价）。 |

除命令外，驾驶时计分板与 BossBar 由 `display.scoreboard` / `display.bossbar` 控制。

## 6. 基础设施

### 道岔 —— 权限 `metrorail.switch`

| 命令 | 说明 |
| :-- | :-- |
| `/mr switch list` | 列出所有已登记道岔。 |
| `/mr switch scan <名字>` | 扫描你附近（`drive.scan-radius`）的铁轨 / 拉杆，登记为一个道岔。 |
| `/mr switch info <名字>` | 查看道岔详情（段数、控制点、当前状态）。 |
| `/mr switch set <名字>` / `/mr switch toggle <名字>` | 转换道岔。 |
| `/mr switch remove <名字>` | 移除道岔登记。 |

> 也可手持**红石火把**（「道岔棒」）右键已登记的**拉杆**来转换道岔。

### 应答器 —— 权限 `metrorail.use`

| 命令 | 说明 |
| :-- | :-- |
| `/mr balise [list\|station\|property\|spawn\|limit\|stop]` | 列出应答器，可按标记过滤。 |
| `/mr origin` | 等价于 `/mr balise spawn`。 |
| `/mr end` | 等价于 `/mr balise stop`。 |

登记方式：**放置 / 修改一块告示牌**，第 1 行写 `[标记]`，第 2 行起写数据；`SignChangeEvent` 会自动登记并把方块坐标登记到 `balises.yml`。拆掉牌子会自动注销。详见 [自动牌子.md](自动牌子.md)。

### 轨道图 —— 权限 `metrorail.use`（`rebuild` / `export` 需 `metrorail.admin`）

| 命令 | 说明 |
| :-- | :-- |
| `/mr graph status` | 显示世界名、节点数、边数、占用条数、道岔数、应答器数。 |
| `/mr graph inspect` | 同 `status`。 |
| `/mr graph rebuild` | 以你所在位置为起点重新建图（上限 `rail.max-graph-nodes`）。 |
| `/mr graph export` | 把节点 id 列表打到控制台日志。 |

## 7. 列控

### 行车许可 MA —— 权限 `metrorail.drive`

| 命令 | 说明 |
| :-- | :-- |
| `/mr ma status` | 显示剩余 MA 距离、原因、段数。 |
| `/mr ma demand [段数]` | 预约前方若干段进路（默认 3）。 |
| `/mr ma release` | 释放本车全部占用。 |
| `/mr ma ack` | 确认行车许可（清除告警）。 |

### 列控模式 —— 权限 `metrorail.use`（`enforce` 需 `metrorail.admin`）

| 命令 | 说明 |
| :-- | :-- |
| `/mr mode` | 列出可用模式。 |
| `/mr mode <shadow\|bypass\|isolate\|enforce>` | 为当前会话切换模式。 |

| 模式 | 含义 |
| :-- | :-- |
| `shadow` | **影子**：只读计算并显示 MA，**不施制动**（默认、推荐先用）。 |
| `bypass` | **旁路**：完全忽略 MA 计算。 |
| `isolate` | **隔离**：不计算 MA，等同纯手动。 |
| `enforce` | **强制保护**：MA 触发时**强制紧急制动**（实验通道）。 |

## 8. 列车属性与模板 —— 权限 `metrorail.train`

| 命令 | 说明 |
| :-- | :-- |
| `/mr property <列车>` | 列出该列车的全部属性。 |
| `/mr property <列车> <键>` | 读取单个属性。 |
| `/mr property <列车> <键> <值>` | 设置属性（值可含空格）。 |
| `/mr savedtrain list` | 列出列车模板。 |
| `/mr savedtrain save <编组> <名字>` | 把现有编组保存为模板。 |
| `/mr savedtrain spawn <名字>` | 按模板在你面前生成矿车并新建编组。 |
| `/mr savedtrain remove <名字>` | 删除模板。 |

### 可用属性键

| 键 | 含义 |
| :-- | :-- |
| `name` | 列车名 |
| `displayname` | 显示名（缺省回退到 `name`） |
| `trainnumber` | 车次号 |
| `destination` | 目的地 |
| `maxspeed` | 限速 |
| `spacing` | 车厢间距 |

## 9. 其他

| 命令 | 权限 | 说明 |
| :-- | :-- | :-- |
| `/mr help` | — | 显示帮助。 |
| `/mr lang` | `metrorail.admin` | 列出可用语言。 |
| `/mr lang <locale>` | `metrorail.admin` | 切换全局语言并写入 `config.yml`。 |

## 10. 权限总表

| 权限 | 说明 | 默认 |
| :-- | :-- | :-: |
| `metrorail.use` | 基础查询类命令 | 所有人 |
| `metrorail.drive` | 驾驶权相关命令 | 所有人 |
| `metrorail.train` | 编组、列车属性、模板 | OP |
| `metrorail.switch` | 道岔登记与转换 | OP |
| `metrorail.admin` | 重载、建图、网页、`enforce` 模式 | OP |
