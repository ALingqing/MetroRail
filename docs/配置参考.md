# 配置参考

MetroRail 的所有配置都在 `plugins/MetroRail/` 下。改完执行 `/mr reload`（部分项需重启，见下）。

---

## 1. `config.yml`

首次启动自动生成。完整结构：

```yaml
# 语言文件，对应 lang/<locale>.yml
language: zh_CN

# 默认车型（vehicles/<id>.yml 的文件名）
default-vehicle: default

drive:
  # 物理更新间隔（tick），1 = 每 tick
  tick-interval: 1
  # 司机下车时自动释放驾驶权
  release-on-dismount: true
  # 换向需要速度低于该值（blocks/tick）
  reverser-max-speed: 0.05
  # 编组最大节数
  max-consist-size: 20
  # 取车周边扫描半径（格）
  scan-radius: 8.0
  # 快捷栏驾驶：off 关闭；否则填 1-9 表示启用该格
  hotbar-slot: "off"

rail:
  # RailGraph 建图上限节点数
  max-graph-nodes: 20000
  # MA 探测最大距离（格）
  ma-lookahead: 256.0
  # 超速预警阈值倍率（相对当前限速）
  overspeed-warn: 1.10
  # 完整性采样时效（tick）
  tims-timeout-ticks: 40
  # 相邻车厢最大间距（格），0 = 不检查
  tims-max-spacing: 8.0

signs:
  # 自动牌子（station/property/spawn/limit/stop）
  auto-enable: true

display:
  # 驾驶时在计分板显示运行动态
  scoreboard: true
  # 驾驶时显示 BossBar
  bossbar: true

web:
  # 调度网页（SkyPCC 风格）
  enabled: false
  port: 25690
  # 鉴权 token；空则只允许回环访问
  token: ""
  # 仅允许本机访问
  loopback-only: true
```

### 键说明与取值范围

| 键 | 类型 | 默认 | 说明 / 约束 |
| :-- | :-- | :-- | :-- |
| `language` | string | `zh_CN` | 全局语言；玩家可用 `/mr lang` 覆盖 |
| `default-vehicle` | string | `default` | 未指定车型时使用的 `vehicles/<id>` |
| `drive.tick-interval` | int | `1` | 物理更新间隔，最小 1 |
| `drive.release-on-dismount` | bool | `true` | 下车是否自动撤权 |
| `drive.reverser-max-speed` | double | `0.05` | 换向允许的最大速度（blocks/tick） |
| `drive.max-consist-size` | int | `20` | 编组节数上限，最小 1 |
| `drive.scan-radius` | double | `8.0` | 取车 / 扫道岔半径（格），最小 1.0 |
| `drive.hotbar-slot` | string | `off` | `off` 或 `1`~`9`；也可由 `/mr hotbar` 写入 |
| `rail.max-graph-nodes` | int | `20000` | 建图上限，最小 64 |
| `rail.ma-lookahead` | double | `256.0` | MA 探测上限（格），最小 16.0 |
| `rail.overspeed-warn` | double | `1.10` | 超速预警倍率，最小 1.05 |
| `rail.tims-timeout-ticks` | int | `40` | TIMS 采样时效，最小 5 |
| `rail.tims-max-spacing` | double | `8.0` | 相邻车厢间距上限，0 = 不检查 |
| `signs.auto-enable` | bool | `true` | 是否启用告示牌应答器 |
| `display.scoreboard` | bool | `true` | 驾驶时计分板 |
| `display.bossbar` | bool | `true` | 驾驶时 BossBar |
| `web.enabled` | bool | `false` | 是否启动调度网页 |
| `web.port` | int | `25690` | 监听端口；被占用会自动 +1 尝试（最多 +10） |
| `web.token` | string | 空 | 非空则所有 `/api/*` 与页面都要求 token |
| `web.loopback-only` | bool | `true` | 无 token 时是否只允许回环访问 |

### 哪些改动需要重启

| 改动 | 生效方式 |
| :-- | :-- |
| 语言、车型、编组、里程、轨道数据 | `/mr reload` 即可 |
| `web.*` | `/mr reload`（会 stop + start 网页服务） |
| `drive.tick-interval` | `/mr reload`（会重排 ticker） |
| `signs.auto-enable`、`display.*`、`rail.*` | `/mr reload` |
| `vehicles/*.yml` 车型文件内容 | `/mr reload` |

> `/mr reload` 等价于 `MetroRailPlugin#reloadAll()`，会重新读 `config.yml`、重新扫描 `vehicles/`、
> 重新加载编组 / 里程 / 轨道数据，重启网页服务与 ticker。

## 2. `vehicles/<id>.yml`

文件名（去掉 `.yml`）就是车型 id，例如 `default.yml` → `/mr drive default`。

```yaml
# 车型物理参数
# speed 单位：blocks / tick（0.4 ≈ 8 格/秒）
display-name: "标准编组"
max-speed: 0.40
acceleration: 0.020
brake: 0.030
emergency-brake: 0.100
friction: 0.010
```

| 键 | 默认 | 约束 | 说明 |
| :-- | :-- | :-- | :-- |
| `display-name` | 文件名 | — | HUD / 列表里显示的名字 |
| `max-speed` | `0.40` | ≥ 0.01 | 最高速度，**blocks/tick** |
| `acceleration` | `0.020` | ≥ 0.001 | 牵引加速度（每 tick 增加的速度） |
| `brake` | `0.030` | ≥ 0.001 | 常用制动减速度（同时用于站停牌反推制动距离） |
| `emergency-brake` | `0.100` | ≥ 0.001 | 紧急制动减速度 |
| `friction` | `0.010` | ≥ 0.0 | 惰行阻力 |

**内置车型**：

| id | 显示名 | 最高速度 | 特点 |
| :-- | :-- | :-- | :-- |
| `default` | 标准编组 | 0.40 | 平衡 |
| `express` | 快速编组 | 0.60 | 更快、加速更强、制动稍弱、阻力更小 |

> 如果 `vehicles/` 下**一个文件都没有**，插件会把内置的 `default` / `express` 释放出来。

### 速度单位换算

插件内部统一用 **blocks/tick**；`1 block/tick = 20 block/s = 72 km/h`（近似，按 1 block ≈ 1 m 计）。

| blocks/tick | km/h（约） | 格/秒 |
| :-- | :-- | :-- |
| 0.10 | 7.2 | 2.0 |
| 0.20 | 14.4 | 4.0 |
| 0.40 | 28.8 | 8.0 |
| 0.60 | 43.2 | 12.0 |

## 3. `lang/<locale>.yml`

内置 `zh_CN.yml`、`en_US.yml`。结构是 `前缀 + 键值对`：

```yaml
prefix: "&b&l[MetroRail]&r"
no-permission: "&c你没有权限执行该操作。"
drive-acquired: "&a已接管矿车（车型 &f%s&a），获得驾驶权。"
```

- 值里可用 `&` 颜色代码（内部转 `§`），`%s` 是占位符，按调用处顺序替换。
- 想要新语言：复制一份改成目标 locale 文件名（如 `ja_JP.yml`），放进 `lang/`，然后 `/mr lang ja_JP`。
- **已经存在于磁盘的语言文件不会被 jar 覆盖**，升级后如遇新键缺失，会回退到内置默认。

## 4. 数据文件（运行时生成）

| 文件 | 由谁读写 | 内容 |
| :-- | :-- | :-- |
| `trains.yml` | `DriveManager` | 编组（id → 车厢 UUID 列表、owner） |
| `mileage.yml` | `MileageStore` | 玩家 UUID → 累计里程 |
| `graph.yml` | `GraphStore` | 轨道图（节点 / 边） |
| `switches.yml` | `SwitchRegistry` | 道岔登记 |
| `balises.yml` | `BaliseRegistry` | 应答器登记 |
| `occupancy.yml` | `OccupancyLedger` | 占用账本（边 → 持有者集合） |
| `rail-trains.yml` | `TrainStore` | 列车属性 + savedtrain 模板 |
| `web/` | `DispatchWebServer` | 页面静态资源 |

> 这些文件一般**不需要手工编辑**。若确实要改（如批量清理应答器），改完执行 `/mr reload`。

## 5. `plugin.yml`（供二次开发参考）

```yaml
name: MetroRail
main: cn.aqcraft.metrorail.MetroRailPlugin
api-version: '1.18'
depend: [Metro]
commands:
  mr:
    aliases: [metrorail, mrail]
```

`depend: [Metro]` 是**硬依赖** —— 想让 MetroRail 在没有 Metro 时也能加载，需要改成 `softdepend`，
并自行处理 `MetroHook` 的反射失败路径。
