# 自动牌子（应答器）

MetroRail 的「应答器」就是**告示牌**。你不用执行任何登记命令 —— 只要放一块牌子并写好内容，
插件监听 `SignChangeEvent`，会自动把它登记为应答器（写入 `balises.yml`）；拆掉牌子会自动注销。

开关：`signs.auto-enable`（默认 `true`），关掉后牌子不再生效。

---

## 1. 牌子格式

一块告示牌的 4 行里：

| 位置 | 内容 |
| :-- | :-- |
| **第 1 行** | 标记，必须写成 `[标记]`（方括号，全小写更保险） |
| **第 2~4 行** | 数据；空行会被忽略 |

支持的 5 种标记：

| 标记 | 作用 | 状态 |
| :-- | :-- | :-: |
| `[station]` | 车站：按制动距离递减限速，靠站停车并转入 SB | ✅ 已生效 |
| `[stop]` | 强制停车：进入 8 格内立即停稳 | ✅ 已生效 |
| `[limit]` | 限速：让 MA 的 `limitSpeed` 取更低值 | ✅ 已生效 |
| `[property]` | 属性牌（如 `V_target`），第 2 行写 `键 值` | ⚠️ 已登记 / 可查询，自动应用为扩展点 |
| `[spawn]` | 生成点 / 清除点（`handleSpawn`） | ⚠️ 已实现接口，自动触发为扩展点 |

查看已登记的应答器：

```
/mr balise                 # 全部
/mr balise station         # 只列出 [station]
/mr origin                 # 等价于 /mr balise spawn
/mr end                    # 等价于 /mr balise stop
```

## 2. `[station]` —— 车站自动停

### 写法

```
┌─────────────────┐
│ [station]       │   ← 第 1 行：标记
│ 人民广场|5      │   ← 第 2 行：站名|停车距离(格)
│                 │
│                 │
└─────────────────┘
```

第 2 行格式：`站名|停车距离`

- **站名**：随意，会显示在 HUD / 事件里。
- **停车距离**：可选，从牌子位置往前多少格才算「车头到位」。不写则默认 0。

### 行为

对距离牌子 **64 格以内**的驾驶会话：

1. 计算 `remaining = 距离 − 停车距离`。
2. `remaining > 1` 时，用制动能力反推一个安全速度
   $v_{允许} = \sqrt{2 \cdot a_{制动} \cdot remaining}$，若当前速度更快就把它压到该值（转入 `SB` 常用制动）。
3. `remaining ≤ 1` 时**停稳**：速度归零、级位回 `n`、状态转 `SB`，并在占用账本里 `hold` 一个
   `station@<站名>` 的共享预留。

> 制动能力 $a_{制动}$ 取自当前车型的 `brake` 值。所以车型选得越「软」，制动就越早开始。

## 3. `[stop]` —— 强制停车

```
┌──────────┐
│ [stop]   │
│          │
│          │
│          │
└──────────┘
```

进入 **8 格**内立刻把速度归零、级位回 `n`、状态转 `FS`（全常用制动）。
如果你就在牌子旁 2 格内，还会收到一条 `已按 [stop] 牌停车` 的提示。

适合用在**终点站 / 车挡 / 检修区**前，做一道「兜底」。

---

## 4. `[limit]` —— 限速牌

```
┌──────────┐
│ [limit]  │
│ 0.3      │   ← 第 2 行：限速值，单位 blocks/tick
│          │
│          │
└──────────┘
```

MA 沿轨道推进时，若恰好走到该牌子所在节点，就把 `limitSpeed` 取为
`min(当前限速, 牌值)` —— 也就是说**这是一条「这条线路沿途的最低限速」**。

> 单位是 **blocks/tick**（`0.4` ≈ 8 格/秒）。写非数字会被忽略。

---

## 5. `[property]` —— 属性牌（扩展点）

```
┌──────────────────┐
│ [property]       │
│ V_target 0.3     │   ← 第 2 行：键 值
│                  │
│                  │
└──────────────────┘
```

第 2 行起每行按空白拆成 `键 值`，可以用 `AutoSignService#propertyValue(balise, key, fallback)` 读取。

当前版本已支持**登记与读取接口**，但「自动把 `V_target` 应用到列车」尚未接线（规划中）。
如果你要写自己的附属，可以直接调用 `plugin` 暴露的 `RailServices` / `AutoSignService`。

---

## 6. `[spawn]` —— 生成 / 清除点（扩展点）

```
┌──────────┐
│ [spawn]  │
│          │
│          │
│          │
└──────────┘
```

`AutoSignService#handleSpawn(balise, true|false)`：

- `true`：在牌子位置**上方 1 格**生成一节矿车。
- `false`：清除牌子 2 格半径内的全部矿车，返回清除数量。

当前版本已实现该接口，但**尚未接线到红石 / 定时器**（规划中）。可用于二次开发，
或先当作「地点标记」使用。

## 7. 排查

| 现象 | 处理 |
| :-- | :-- |
| 牌子不生效 | 第 1 行是不是**完整**的 `[station]`（方括号不能少、不能有其它字符）？ |
| 牌子没出现在 `/mr balise` | 标记拼写不对（只认 `station/property/spawn/limit/stop`），或 `signs.auto-enable` 为 false。 |
| 站停位置不对 | 调整第 2 行的「停车距离」，或把牌子挪到车头目标位。 |
| 车站牌不制动 | 确认在驾驶中（`/mr drive`）、且距牌子 64 格内、状态不是 `PT`。 |
| 拆了牌子还在列表 | 拆掉的是牌子方块（任意 `*_SIGN`）才会注销；确认方块类型。 |
| 想批量清理 | 直接编辑 `plugins/MetroRail/balises.yml` 后 `/mr reload`。 |
