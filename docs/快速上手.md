# 快速上手：十分钟开动一列车

本教程带你把「接管矿车 → 起步 → 停车 → 释放」跑通一遍。
命令前缀统一是 **`/mr`**。

---

## 0. 前置

- 服务器已安装 **MetroRail** 与 **Metro**（见 [安装与部署.md](安装与部署.md)）。
- 你有 `metrorail.use` 与 `metrorail.drive` 权限（默认所有人都有）。
- 你身边有一节**矿车**（可以让 Metro 生成，或自己放置）。

---

## 1. 接管一列车

站在矿车**旁边**（默认 8 格内），执行：

```
/mr drive
```

成功会提示：

```
[MetroRail] 已接管矿车（车型 default），获得驾驶权。
```

如果你有多个车型（`vehicles/*.yml`），可以指定：

```
/mr drive express
```

查看可用车型：

```
/mr vehicle list
```

> **提示**：驾驶权是「一人一车」独占的。别人已经接管的车，你会收到「该矿车已被其他司机接管」。

---

## 2. 熟悉界面

三种操盘方式，任选其一或混用：

| 方式 | 命令 | 说明 |
| :-- | :-- | :-- |
| 图形驾驶室 | `/mr cab` | 点击按钮操作级位 / 换向 / 鸣笛 / 列控模式 |
| 快捷栏驾驶 | `/mr hotbar <1-9>` | 在该格位放「驾驶杆」，用 1~9 格切换 B7→P4 |
| 纯命令 | `/mr p1` 等 | 最直接，适合脚本 / 绑定按键 |

同时，屏幕上的**计分板**与 **BossBar** 会实时显示速度、级位、车型、编组；
开启列控后还会多出「模式 / 状态 / MA / 完整性」几行。

---

## 3. 确认方向并起步

1. 设定换向器（必须停稳或极低速才能换）：

   ```
   /mr reverser forward
   ```

   - `forward` 前进 ｜ `neutral` 空档 ｜ `backward` 后退

2. 逐级加牵引：

   ```
   /mr p1
   /mr p2
   /mr p3
   /mr p4
   ```

   级位越高加速度越大；`P4` 是满牵引。

3. 想惰行（不给牵引也不制动）：

   ```
   /mr n
   ```

---

## 4. 减速与停车

常用制动共 7 级：

```
/mr b1     # 最轻
/mr b4
/mr b7     # 满常用制动
```

要停车时也可以先惰行滑行，再用制动收尾。

**紧急制动**（相当于急停，减速率最大）：

```
/mr eb
```

---

## 5. 查看运行数据

```
/mr status
```

会列出：驾驶权状态、当前速度（格/tick 与 km/h）、车型、编组、Metro 对接状态。

想单独看里程：

```
/mr mileage
```

---

## 6. 释放驾驶权

```
/mr release
```

会提示本次运行里程，并清理 HUD。

**以下情况会自动撤权**（无需手动 release）：

- 你**下车**
- 你**掉线**
- 服务器**重载 / 关闭**插件

---

## 7. 下一步

- 想让矿车停得更准？用 [自动牌子](自动牌子.md) 的 `[station]` 牌做距离制动站停。
- 想多节车厢一起跑？用**编组**：
  ```
  /mr train scan           # 把身边的矿车登记成一个新编组
  /mr train append c1      # 再加入一节
  /mr train list           # 查看
  ```
- 想显示「前方占用 / 行车许可」？进 [列控与信号](列控与信号.md) 建轨道图并打开影子 MA。
- 想在浏览器里看运行图？开 [调度网页](调度网页.md)。

---

## 8. 一页速记

```
/mr drive                 接管矿车
/mr reverser forward      前进
/mr p4                    满牵引
/mr n                     惰行
/mr b4                    中等制动
/mr eb                    紧急制动
/mr release               释放
```
