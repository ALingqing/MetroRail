# 调度网页（SkyPCC 风格）

MetroRail 自带一个轻量 HTTP 调度台：**实时轨道图（占用着色）+ 列车列表 + 道岔 / 应答器详情 + 事件日志 + 网页道岔控制**。
实现基于 JDK 自带的 `com.sun.net.httpserver`，不引入额外依赖。

---

## 1. 启用

编辑 `plugins/MetroRail/config.yml`：

```yaml
web:
  enabled: true          # 默认 false，改成 true 才会启动
  port: 25690            # 监听端口
  token: ""              # 鉴权 token，留空则只允许本机访问
  loopback-only: true    # 仅允许回环地址访问
```

改完 `/mr reload`（或重启服务器）。

启动日志：

```
[MetroRail] 调度网页已启动： http://127.0.0.1:25690/（页面文件夹：plugins/MetroRail/web）
```

> 端口被占用时，插件会自动依次尝试 `port+1` ~ `port+10`，并在日志里打印**实际**端口。
> 用 `/mr web` 可以随时查看当前端口 / 启用状态 / 鉴权状态 / 页面目录。

---

## 2. 页面文件可以随意改

首次启动时，`index.html` / `style.css` / `app.js` 会从 jar 释放到 `plugins/MetroRail/web/`。
之后**每次请求都从磁盘读取**（文件缺失才回退到 jar 内版本），所以你：

- 改完 `web/app.js` → **刷新浏览器**即可生效，**不用重启插件**。
- 想还原默认页面 → 删掉对应文件，刷新后会重新从 jar 释放。

本地开发时也可以直接开发 `src/main/resources/web/`，仓库里的 `preview/index.html` 是一个
**离线预览页**（用模拟数据 + 复用真实 `style.css`），改样式时能即时看到效果。

## 3. 访问与鉴权

| 场景 | 需要做什么 |
| :-- | :-- |
| 本机浏览器访问 | 直接开 `http://127.0.0.1:<port>/` |
| 外机访问（未设 token） | 会被拒绝：`403 forbidden`。需要设 token 或关掉 `loopback-only` |
| 外机访问（已设 token） | URL 带 `?token=<token>`，或请求头带 `X-MetroRail-Token: <token>` |

鉴权规则（源码 `authorized()`）：

- **设了 token**：任何来源都必须提供正确 token。
- **没设 token**：只允许**回环地址**（`127.0.0.1` / `::1` / `localhost`）访问；除非把 `loopback-only` 设为 `false`。

> **安全提醒**：`token` 是明文放在 `config.yml` 里的共享密钥。要暴露到公网时，
> 建议同时用反向代理（Nginx / Caddy）加 HTTPS + IP 白名单 + 独立端口。

## 4. HTTP API

所有 `/api/*` 都受上面的鉴权约束。

### `GET /api/state`

一次返回全量快照：

```json
{
  "graph":  { "world": "world", "nodes": 1284, "edges": 3902 },
  "track":  [
    { "from": [x,y,z], "to": [x,y,z], "occupied": false }
  ],
  "trains": [
    { "driver": "aqing", "train": "c1", "vehicle": "default",
      "speed": 0.182, "speedKmh": 6.55, "notch": "p2", "reverser": "forward",
      "mode": "shadow", "state": "SB", "eoa": 142.3, "intact": true }
  ],
  "switches": [
    { "id": "west_points", "positions": 2, "location": "world:x:y:z" }
  ],
  "balises": [
    { "tag": "station", "name": "人民广场|5", "id": "world:x:y:z", "pos": [x,y,z] }
  ]
}
```

| 字段 | 说明 |
| :-- | :-- |
| `track[].occupied` | 该有向边是否**被任意列车持有**（用于地图着色） |
| `trains[].eoa` | 授权终点距离（格）；无图时为 `-1` |
| `trains[].intact` | 完整性是否正常 |
| `balises[].name` | 牌子第 2 行起的第一条数据 |

### `GET /api/events`

返回最近 **100** 条事件：

```json
[
  { "time": "12:03:41", "category": "drive", "message": "aqing 接管矿车 c1" },
  { "time": "12:04:02", "category": "switch", "message": "aqing 转换道岔 west_points" }
]
```

`category` 常见取值：`drive`、`switch`、`ma`、`mode`、`graph`、`balise`。

### `GET /api/switch?name=<道岔名>`

**转换**指定道岔（写操作！）：

```json
{ "switch": "west_points", "changed": 2 }
```

找不到返回 `404 {"error":"switch-not-found"}`；未鉴权返回 `401 {"error":"unauthorized"}`。

> 该接口会真的扳动道岔，并写入事件日志（`web 转换道岔 ...`）。公网暴露时务必配 token。

### 其他路径

非 `/api/` 路径按**静态文件**处理：`/` → `index.html`，其余按相对路径取 `plugins/MetroRail/web/` 下的文件，
找不到再回退 jar 内置。带 `..` 的路径直接 `400`。

## 5. 与 Metro 自带地图的关系

Metro 侧可能已经装了 BlueMap / Dynmap / Squaremap 之类做**线网级**地图；
MetroRail 的调度台是**运行级**的：它画的是 RailGraph 的有向边 + **实时占用** + **实时列车**，
两者用途不同，可以并存。

## 6. 排查

| 现象 | 处理 |
| :-- | :-- |
| `/mr web` 提示「调度网页未启用」 | `web.enabled` 是 false。 |
| 浏览器 403 forbidden | 你在非回环地址访问且没带 token；设 token 或临时 `loopback-only: false`。 |
| 地图空白 | 还没建图：`/mr graph rebuild`。 |
| 占用不着色 | 占用来自 `/mr ma demand` 或状态机会话；先让列车真的预约进路。 |
| 改了页面没变化 | 确认改的是 `plugins/MetroRail/web/` 下的文件（不是 jar 里的），并强制刷新（Ctrl+F5）。 |
| 端口冲突反复失败 | 看日志里报的 `port+N`；把 `web.port` 改成一个更大的空闲端口。 |
